# Hepatitis B Virus (HBV) Phylogenetic Analysis

## 📌 Overview
This repository contains a phylogenetic analysis of Hepatitis B Virus (HBV) isolates to study evolutionary relationships and strain variations using Multiple Sequence Alignment (MSA).

## 🛠️ Tools Used
- **Database:** NCBI Nucleotide / BLAST
- **Multiple Sequence Alignment:** ClustalW / Clustal Omega
- **Visualization:** Phylogram / ETE Tree Viewer

## 🧬 Methodology
![Hepatitis B Phylogenetic Tree](input.fa.final_tree.nw.png)
1. Retrieved HBV nucleotide sequence from NCBI.
2. Performed multiple sequence alignment to identify conserved regions and variations.
3. Constructed a midpoint-rooted phylogram to analyze genetic distance between strains.
